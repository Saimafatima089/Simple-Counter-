Simple Counter

This is a simple counter project. I made this to practice my JavaScript . 

What it does:
- Clicking + increases the number.
- Clicking - decreases the number.
- Clicking Reset makes it 0 again.

What I used:
- HTML for buttons and text.
- CSS to make the box look nice and center it.
- JavaScript for click events.

What I learned:
- How to connect buttons to JavaScript.
- How to use addEventListener click.
- How to fix the code when a button stops working.
